              Controls

              W / ↑Throttle
              S / ↓Brake (hold when stopped to reverse)
              A DSteer • in the air: whip / scrub (bikes)
              Q / ELean back / forward • in the air: backflip / front flip
              Shift + A/D in the airFlat spin (360s)
              Hold 1 2 3 4 in the airSuperman, Nac-Nac, Heel Clicker, Cliffhanger - let go before you land!
              ShiftClutch - hold, rev, release for a burst (wheelies)
              SpaceRear brake - locks the rear for slides
              RReset onto the track
              TQuick retry (Time Trial / Practice / Freestyle)
              CChange camera
              Right mouse + dragLook around
              Esc / PPause
              F3FPS counter

              Tricks: land several in a row for a combo multiplier (up to x4). Land with the wheels matching the slope for a Perfect landing (x1.5).
              Gamepad: triggers = throttle/brake, left stick = steer/lean, A = reset, Y = camera, X = rear brake, RB = clutch.
